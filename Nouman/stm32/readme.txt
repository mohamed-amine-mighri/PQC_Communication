Go to STMicroelectronics' official STM32CubeWB page:
STM32CubeWB official page
Find STM32CubeWB and download the firmware package.
You may need to sign in/create an ST account.
Install/extract the package.
You should then have something like:
C:\Users\BIG BANG\STM32Cube\Repository\
└── STM32Cube_FW_WB_V1.24.0\
    └── Projects\
        └── P-NUCLEO-WB55.Nucleo\
            └── Applications\
Than in Application make a new folder. 
Copy the desire 'BLE_p2pClient' and 'BLE_p2pServer' code into the folder.
Open .project file inside STM32CubeIDE
Build and run the code on boards.
